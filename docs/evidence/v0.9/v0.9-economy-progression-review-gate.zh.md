# v0.9 Economy & Progression / 经济与成长 Review Gate

Version: v0.9

Language: Chinese

Review Status: Approved

## 设计摘要

v0.9 为 Muse Game Workshop 增加 Economy & Progression / 经济与成长包。它定义团队如何在实现前记录 economy model / 经济模型、progression map / 成长线地图、resource/reward table / 资源与奖励表和 tuning loop / 数值调优闭环。它连接现有 Game Design & Systems / 策划与系统设计包、Genre Tracks / 类型流程分支和 Godot Prototype Asset Kit / Godot 原型资产包计划，但不创建引擎文件或资产。

## 执行计划

1. 增加 `economy-progression.zh.md` 和 `economy-progression.en.md`。
2. 增加四个模板：economy model、progression map、resource/reward table 和 tuning loop。
3. 增加 Tactics / 战棋类 no-code dry-run evidence。
4. 增加 v0.9 completion evidence。
5. 增加 `tools/checks/check-v0.9-economy-progression`。
6. 更新 README、文档包索引、AGENTS、roadmap、delivery plan、testing strategy、doc-pair checks、template metadata checks 和 startup prompts。

## 影响范围

- 仅文档。
- 仅模板新增。
- 仅 static check 新增。
- 不写 Godot 或 Unreal 代码。
- 不创建引擎场景。
- 不生成或导入资产。
- 不做后端或 telemetry service。

## Review 决策

- 经济与成长在 v0.9 作为设计包进入，不作为实现包进入。
- Tactics / 战棋类作为第一条 dry-run 验证分支，因为 action points / 行动点、stamina / 体力、cooldowns / 冷却、mission rewards / 关卡奖励、unit growth / 单位成长和 skill unlocks / 技能解锁能清楚暴露闭环。
- 商业化后台、真实支付、付费设计、真实 telemetry service、LiveOps 执行和引擎实现都排除。
