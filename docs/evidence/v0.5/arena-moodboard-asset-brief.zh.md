# BR-AIART-002 Arena Moodboard Asset Brief

版本：v0.5b

语言：中文

日期：2026-06-09

## 1. Asset Summary

- Asset ID: `BR-AIART-002`
- Asset Name: Arena moodboard
- Asset Type: Environment / moodboard
- Target State: `reference-only`
- Target Engine: None
- Owner: Art Director
- Review Status: Approved for dry run brief

## 2. Gameplay Purpose

Arena moodboard / 场景情绪板用于探索战斗场地的色彩、材质和氛围边界。它必须服务 Boss 起手、玩家位置、危险区域和反击窗口的可读性。

## 3. Visual Requirements

- 背景对比度低于玩家和 Boss。
- 地面必须能支持方向、距离和边界判断。
- 主色不与 player cyan、boss red-orange、counter mint/gold 冲突。
- 材质方向可以是石质、金属、训练场或抽象竞技场，但必须低噪声。

## 4. Forbidden Directions

- 不使用复杂背景抢走战斗注意力。
- 不用暗红/暗蓝大面积覆盖核心反馈色。
- 不复刻特定商业游戏竞技场。
- 不使用真实品牌、宗教符号或敏感图案作为核心视觉。

## 5. AI Use Boundary

AI 可用于生成 mood thumbnails、palette boards 和 material reference。输出只能作为 `reference-only`，不得直接用作最终背景图或贴图。

## 6. Provenance Requirements

- Tool and model/service.
- Prompt and negative prompt.
- Palette instructions.
- Reference source policy.
- Human selection notes.
- License and commercial-use notes.
- Content Credentials if available.

## 7. Review Criteria

- 是否保持战斗主体可读。
- 是否支持 Boss Rush 的试炼氛围。
- 是否能转化为关卡灰盒、材质规范或灯光方向。
- 是否存在未授权相似性或文化风险。

## 8. Engine Validation Notes

当前状态为 `reference-only`，不进入引擎。若转为 prototype background、tile texture 或 3D environment props，必须补尺寸、压缩、导入、性能和场景可读性验证。
