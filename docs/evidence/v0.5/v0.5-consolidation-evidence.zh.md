## 3. 关键决策

### 3.1 v0.5 不再表示发布准备

旧版本计划中，v0.5 曾表示 Publishing Readiness / 发布准备。现在 v0.5 改为路线重排与研究收口。发布准备后移到 v0.13。

### 3.2 v0.10 后继续 v0.11-v0.14

版本顺序调整为：

```text
v0.10 Narrative Design
v0.11 Creative Production Expansion
v0.12 Procedural Content
v0.13 Publishing & Release Readiness
v0.14 LiveOps & Post-launch
v1.0 Reusable Production Pack
```

### 3.3 Godot 对接三层策略

Godot 方向采用：

1. Godot AI：第一对接对象，用于 live editor control。
2. GodotIQ：第二层预留，用于 project understanding。
3. GodotPrompter：内部 workflow skill 设计参考。
