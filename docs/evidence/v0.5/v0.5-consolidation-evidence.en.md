## 3. Key Decisions

### 3.1 v0.5 No Longer Means Publishing Readiness

In the older roadmap, v0.5 meant Publishing Readiness. v0.5 is now Roadmap Rebase & Research Consolidation. Publishing readiness moves to v0.13.

### 3.2 v0.10 Continues To v0.11-v0.14

The version sequence is now:

```text
v0.10 Narrative Design
v0.11 Creative Production Expansion
v0.12 Procedural Content
v0.13 Publishing & Release Readiness
v0.14 LiveOps & Post-launch
v1.0 Reusable Production Pack
```

### 3.3 Three-Layer Godot Strategy

The Godot direction uses:

1. Godot AI: first integration target for live editor control.
2. GodotIQ: second-layer reserve for project understanding.
3. GodotPrompter: internal workflow skill design reference.

## 4. Confirmed Exclusions

v0.5 did not:

- Install Godot AI, GodotIQ, Ziva, Godot-MCP, UE-MCP, or GenOrca Unreal MCP.
- Integrate MCP.
- Generate new assets.
- Import Godot / Unreal assets.
- Create new engine examples.
- Implement release readiness.
