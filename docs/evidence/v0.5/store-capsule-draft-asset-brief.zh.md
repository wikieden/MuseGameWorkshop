# BR-AIART-005 Store Capsule Draft Asset Brief

版本：v0.5b

语言：中文

日期：2026-06-09

## 1. Asset Summary

- Asset ID: `BR-AIART-005`
- Asset Name: Store capsule draft
- Asset Type: Marketing art / store page direction
- Target State: `reference-only`
- Target Engine: None
- Owner: Release Manager + Art Director
- Review Status: Approved for dry run brief

## 2. Communication Purpose

Store capsule draft / 商店胶囊图草案用于探索 Boss Rush 的对外卖点：短促、可读、以反击为核心的 Boss 战试炼。它只用于构图、标题气质和卖点探索，不作为最终商店图。

## 3. Visual Requirements

- 一眼能看出玩家与 Boss 对峙。
- 画面重点应是反击瞬间或 Boss 威胁。
- 构图需要适配 Steam capsule / 商店胶囊图比例，但 v0.5b 不产出真实素材。
- 不得承诺游戏里不存在的角色、场景或品质。

## 4. Forbidden Directions

- 不使用 AI 输出作为最终商店图。
- 不制造与实际 Godot prototype 不符的误导性画面。
- 不复刻其他游戏 key art。
- 不使用未经授权字体、logo 或品牌元素。

## 5. AI Use Boundary

AI 可用于 composition thumbnails、color mood、layout exploration。输出保持 `reference-only`，不得进入 store page、trailer、press kit 或 release package。

## 6. Provenance Requirements

- Tool and model/service.
- Prompt and negative prompt.
- Aspect ratio and layout intent.
- Reference source policy.
- Human selection and rewrite notes.
- Platform disclosure risk.
- Public-facing disclosure draft if later used.

## 7. Review Criteria

- 是否诚实表达当前 demo。
- 是否能传达 counter combat 的核心卖点。
- 是否避免商业游戏相似性和误导性宣传。
- 是否需要 AI usage disclosure。
- 是否适合后续交给人类美术重绘。

## 8. Release Validation Notes

当前状态为 `reference-only`，不允许进入公开商店页面。若后续进入 release readiness，必须补 store page brief、trailer brief、AI usage disclosure、license review 和 final art review。
