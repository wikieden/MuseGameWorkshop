# v0.5 路线重排与研究收口 Review Gate

Review Status: Approved

日期：2026-06-10

语言：中文

## 1. 审批范围

本 review gate 批准 v0.5 作为 Roadmap Rebase & Research Consolidation / 路线重排与研究收口版本完成。

允许范围：

- 收口 v0.5b AI art dry run evidence。
- 落地 Engine AI Development Adapters 研究总纲。
- 落地 Godot / Unreal AI 工具独立调研报告。
- 落地用户反馈扫描。
- 明确 Godot 对接决策：Godot AI 第一对接、GodotIQ 第二层预留、GodotPrompter 作为内部 skill 设计参考。
- 将版本计划从 `v0.10 -> v1.0 / v1.1+` 调整为 `v0.10 -> v0.11 -> v0.12 -> v0.13 -> v0.14 -> v1.0`。
- 新增 v0.5 consolidation evidence 和检查入口。

## 2. 明确不批准

本 review gate 不批准：

- 安装或接入 Godot AI、GodotIQ、GodotPrompter、MCP server 或任何外部工具。
- 创建新的 Godot / Unreal 引擎文件。
- 生成新 AI 美术、动作、音乐、音效或 UI 资产。
- 导入 final 或 release-candidate 资产。
- 接商业创意工具 API。
- 自动发布、商店页发布、账号系统或 LiveOps 实现。

## 3. 完成条件

v0.5 完成必须满足：

- v0.5 AI art dry run 检查通过。
- Engine AI Development Adapters 中英文总纲存在。
- 7 份独立研究报告中英文配对存在。
- 用户反馈扫描中英文配对存在。
- Godot 对接决策写入研究总纲。
- roadmap、delivery plan、overall plan 和 README 对 v0.5-v1.0 版本顺序一致。
- `check-v0.5-consolidation` 通过。

## 4. 后续进入

v0.5 完成后，下一阶段进入 v0.6 Game Design & Systems / 策划与系统设计。

v0.6 不应直接安装 Godot AI 或接 MCP。Godot AI Adapter Dry Run 需要单独 review gate。
