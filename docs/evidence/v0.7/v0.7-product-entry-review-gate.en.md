## Design Summary

v0.7 changes the next Muse Game Workshop step from Genre Tracks to Product Entry & `mgw init` design. The goal is to solve the entry problem of "how does a user use this project to create their own game" before continuing to genre tracks, economy/progression, analytics, narrative, creative production expansion, procedural content, and release readiness.

## Decisions Reviewed

- `mgw init` is a project workspace initializer, not a one-click game generator.
- `--mcp none` is the safe default behavior.
- MCP/editor automation is an optional adapter and requires explicit review.
- Tool adapters must not change the workflow core.
- v0.7 does not write the real CLI.
