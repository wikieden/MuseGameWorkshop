Version: v0.9.3

## Design Summary

v0.9.3 expands Muse Game Workshop from an engine-pair workflow into a shared production-target contract and a tested Three.js browser runtime path. WebGPU is the production direction, WebGL 2 is the required fallback, and deterministic gameplay validation remains separate from rendering and browser smoke validation.
