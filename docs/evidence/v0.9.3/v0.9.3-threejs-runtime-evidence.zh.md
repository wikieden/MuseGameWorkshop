## 制作声明

- Three.js WebGPU 是受支持的最终制作方向。
- 在经过 review 的项目 browser matrix / 浏览器矩阵允许移除前，WebGL 2 必须保留为 fallback。
- Unit、build、browser automation 与 manual browser playtest / 人工浏览器试玩是彼此独立的证据层。
- 已安装依赖或已配置浏览器一旦验证失败，必须判定为阻塞失败，不能记为跳过。

## 边界证据

- v0.9.3 不批准商业化后台、支付、商业化设计、LiveOps 或真实 telemetry 服务。
- 浏览器参考项目是 validation slice / 验证切片，不是最终美术、发布版本最终平衡或 release build。
- Unity、Unreal Engine 与 Godot 的实现声明必须提供各自目标的真实证据。
