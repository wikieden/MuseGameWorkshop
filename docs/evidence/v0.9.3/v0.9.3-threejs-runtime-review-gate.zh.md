# v0.9.3 Multi-target Production Foundation / 多目标制作基础与 Three.js Web Runtime / Web 运行时 Review Gate

Version: v0.9.3

Language: Chinese

Review Status: Approved

## 设计摘要

v0.9.3 将 Muse Game Workshop 从双引擎工作流扩展为共享 Production Target Contract / 制作目标契约与经过测试的 Three.js 浏览器运行路径。WebGPU 是制作方向，WebGL 2 是必需 fallback / 降级路径，确定性玩法验证与渲染、浏览器 smoke validation / 冒烟验证保持分层。

## 执行计划

1. 增加 Production Target Contract 与 Three.js Web Runtime 双语文档。
2. 增加 `threejs-workflow` skill、制作目标映射模板与浏览器试玩模板。
3. 增加数据驱动的 Three.js Boss Rush 浏览器参考项目。
4. 增加 unit、production build 与条件式 browser automation 验证。
5. 增加成对 evidence 与 `check-v0.9.3-threejs-runtime` 入口。

## 影响范围

- 制作工作流文档。
- Workflow skill 与模板。
- Three.js 参考运行时与测试。
- Static、unit、build 与 browser validation 证据。
