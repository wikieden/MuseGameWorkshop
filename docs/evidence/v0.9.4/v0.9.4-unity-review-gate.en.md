## Design Summary

v0.9.4 adds Unity as a supported production target at the documentation, workflow-skill, target-mapping, and validation-contract layers. It separates static workflow completion from Unity Editor, EditMode, PlayMode, and player-build evidence.

## Execution Plan

1. Add bilingual Unity Workflow documentation.
2. Add the `unity-workflow` skill and connect it to the shared Production Target Contract.
3. Define ScriptableObject, Assembly Definition, scene, prefab, input, UI, test, and build responsibilities.
4. Add paired validation evidence and the `check-v0.9.4-unity` entry point.
5. Run Unity Editor smoke only when an editor executable is available.

## Impact Scope

- Production workflow documentation.
- Unity workflow skill and target-mapping contract.
- Static validation and conditional editor smoke evidence.
- No new Unity gameplay project in this scope.
