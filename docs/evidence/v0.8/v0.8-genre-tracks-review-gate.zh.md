## 明确边界

v0.8 不批准：

- 真实资产生成。
- `.glb` / `.gltf` 创建。
- Godot 工程创建或修改。
- Unreal 工程创建或修改。
- MCP 安装。
- Godot AI、Godot-MCP、UE-MCP 或编辑器自动化接入。
- 真实 `mgw` CLI 实现。
- final 或 release-candidate 资产导入。
