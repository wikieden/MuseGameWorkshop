# v0.6 Game Design & Systems Review Gate

Review Status: Approved

Date: 2026-06-10

Language: English

## 1. Approved Scope

This review gate approves v0.6 as the Game Design & Systems version.

Allowed scope:

- Add the bilingual v0.6 Game Design & Systems overview.
- Add system design, combat design, encounter design, tuning plan, and playtest hypothesis templates.
- Add the Boss Rush / Action design dry run.
- Add the Tactics design dry run.
- Add v0.6 evidence and a check entry point.
- Update README, documentation index, roadmap, delivery plan, overall plan, and testing strategy so the next step points to v0.7 Genre Tracks.

## 2. Explicitly Not Approved

This review gate does not approve:

- Creating new Godot or Unreal engine files.
- Installing or integrating Godot AI, GodotIQ, GodotPrompter, MCP servers, or any external tool.
- Generating or importing art, animation, music, SFX, UI, or release-candidate assets.
- Starting the full v0.7 genre-track package.
- Implementing economy systems, progression systems, telemetry, procedural content, publishing readiness, or LiveOps.

## 3. Completion Conditions

v0.6 is complete only when:

- The bilingual Game Design & Systems overview exists.
- Five v0.6 design templates exist and include the shared metadata block.
- Boss Rush and Tactics dry-run evidence exists in both languages.
- The dry runs cover pillars, systems, combat or rules, encounters, parameters, and playtest hypotheses.
- README, roadmap, delivery plan, overall plan, and testing strategy agree that v0.6 is complete and v0.7 is next.
- `check-v0.6-game-design-systems` passes.
- v0.6 creates no new engine files, installs no MCP, and generates or imports no assets.

## 4. Next Step

After v0.6, the next stage is v0.7 Genre Tracks.

v0.7 is where Action, Roguelike, RPG, Puzzle, Visual Novel, Tactics, and Adventure / AVG workflow branches formally expand.
