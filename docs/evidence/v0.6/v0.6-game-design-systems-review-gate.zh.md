# v0.6 策划与系统设计 Review Gate

Review Status: Approved

日期：2026-06-10

语言：中文

## 1. 审批范围

本 review gate 批准 v0.6 作为 Game Design & Systems / 策划与系统设计版本落地。

允许范围：

- 新增 v0.6 Game Design & Systems 中英文总纲。
- 新增 system design、combat design、encounter design、tuning plan 和 playtest hypothesis 模板。
- 新增 Boss Rush / 动作玩法 design dry run。
- 新增 Tactics / 战棋类 design dry run。
- 新增 v0.6 evidence 和检查入口。
- 更新 README、文档索引、roadmap、delivery plan、overall plan 和 testing strategy，使其指向 v0.7 Genre Tracks / 类型流程分支。

## 2. 明确不批准

本 review gate 不批准：

- 创建新的 Godot / Unreal 引擎文件。
- 安装或接入 Godot AI、GodotIQ、GodotPrompter、MCP server 或任何外部工具。
- 生成或导入美术、动作、音乐、音效、UI 或 release-candidate 资产。
- 开始完整 v0.7 类型流程分支包。
- 实现经济系统、成长系统、数据埋点、程序化内容、发布准备或 LiveOps。

## 3. 完成条件

v0.6 完成必须满足：

- Game Design & Systems 中英文总纲存在。
- 5 个 v0.6 设计模板存在并包含共享 metadata block。
- Boss Rush 和 Tactics dry run 中英文证据存在。
- dry run 覆盖设计支柱、系统、战斗或规则、遭遇、参数和试玩假设。
- README、roadmap、delivery plan、overall plan 和 testing strategy 对 v0.6 完成与 v0.7 下一步的描述一致。
- `check-v0.6-game-design-systems` 通过。
- v0.6 没有创建新引擎文件、没有安装 MCP、没有生成或导入资产。

## 4. 后续进入

v0.6 完成后，下一阶段进入 v0.7 Genre Tracks / 类型流程分支。

v0.7 才正式扩展 Action / 动作、Roguelike / 肉鸽、RPG、Puzzle / 解谜、Visual Novel / 视觉小说、Tactics / 战棋类和 Adventure / AVG 冒险的类型流程。
