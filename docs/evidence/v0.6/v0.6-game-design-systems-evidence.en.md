## 1. Version Positioning

v0.6 is the Game Design & Systems version.

It moves Muse Game Workshop from pitch, core loop, and mechanic spec into a handoff chain for systems, combat, encounters, tuning, and playtest hypotheses. It is not an engine implementation version and not the full genre-track version.

## 3. Key Decisions

### 3.1 v0.6 Focuses On Design And System Handoff

v0.6 does not expand the full genre workflow. Boss Rush and Tactics are design dry runs used to prove that the same design process can serve Action and Tactics structures.

### 3.2 v0.7 Handles Full Genre Tracks

v0.7 will formally support Action, Roguelike, RPG, Puzzle, Visual Novel, Tactics, and Adventure / AVG.

### 3.3 Design Hypotheses Must Feed Playtests

v0.6 treats playtest hypotheses as a core deliverable. Future changes should first state what they are trying to validate, then choose parameter, encounter, or feedback changes.

## 4. Boundary Confirmation

v0.6 did not:

- Create new Godot or Unreal engine files.
- Install or integrate Godot AI, GodotIQ, GodotPrompter, MCP servers, or external tools.
- Generate or import new assets.
- Implement economy systems, progression systems, telemetry, procedural content, publishing readiness, or LiveOps.
- Start the full v0.7 genre-track package.
