## 1. 版本定位

v0.6 是 Game Design & Systems / 策划与系统设计版本。

它把 Muse Game Workshop 从 pitch、core loop 和 mechanic spec 推进到系统、战斗、遭遇、调优和试玩假设的交付链路。它不是引擎实现版本，也不是完整类型流程分支版本。

## 3. 关键决策

### 3.1 v0.6 专注策划与系统交接

v0.6 不扩展完整类型流程。Boss Rush 和 Tactics 只作为 design dry run，用来证明同一套策划流程可以服务动作玩法和战棋类玩法。

### 3.2 v0.7 再做完整类型流程分支

v0.7 将正式支持 Action / 动作、Roguelike / 肉鸽、RPG、Puzzle / 解谜、Visual Novel / 视觉小说、Tactics / 战棋类和 Adventure / AVG 冒险。

### 3.3 设计假设必须进入试玩

v0.6 把 playtest hypothesis / 试玩假设作为核心交付物。后续修改要先说明要验证什么，再选择参数、遭遇或反馈调整。

## 4. 禁止范围确认

v0.6 未做：

- 未创建新的 Godot / Unreal 引擎文件。
- 未安装或接入 Godot AI、GodotIQ、GodotPrompter、MCP server 或外部工具。
- 未生成或导入新资产。
- 未实现经济系统、成长系统、数据埋点、程序化内容、发布准备或 LiveOps。
- 未开始完整 v0.7 类型流程分支。
