# Adventure / AVG 冒险类型分支

状态：Draft  
版本范围：v0.8  
Review Status: Approved

## Player Promise / 玩家承诺

玩家探索场景、调查线索、使用物品或对白，并通过可理解的发现推进。

## Core Loop Emphasis / 核心循环重点

```text
进入场景 -> 检查线索 / 对话 / 使用物品 -> 更新认知 -> 解锁路径或对白 -> 推进场景
```

## Required Deliverables / 必要交付物

- scene flow / 场景流程。
- clue list / 线索清单。
- interaction table / 交互表。
- inventory or item-use rules / 物品栏或道具使用规则。
- dialogue gate notes / 对白门槛说明。
- failure and hinting plan / 失败与提示计划。
- 调查可读性 playtest checklist。

## Prototype Validation / 原型验证

原型必须证明玩家知道该看哪里、什么状态改变了，以及为什么能推进。

## Asset And UX Needs / 资产与 UX 需求

- 可交互物、出口、线索状态、物品状态和对白可用性必须可读。
- 过度氛围化的视觉不能隐藏必要信息。

## QA And Playtest Checks / 测试与试玩检查

- 玩家能否找到关键线索，而不是像素级乱点？
- 物品和对白门槛是否合理？
- 反馈是否解释了状态变化？

## Explicit Exclusions / 明确不做

- 完整场景列表。
- 最终背景美术。
- 完整配音或演出实现。
- 大规模分支叙事。
