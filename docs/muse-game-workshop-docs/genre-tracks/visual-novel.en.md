# Visual Novel Track

Status: Draft  
Version scope: v0.8  
Review Status: Approved

## Player Promise

The player follows characters, makes narrative or relationship choices, and sees meaningful story consequences.

## Core Loop Emphasis

```text
read scene -> understand character intent -> choose response / route -> see consequence -> update relationship / branch -> continue
```

## Required Deliverables

- Premise and theme.
- Character brief.
- Route map.
- Dialogue sample.
- Choice consequence table.
- UI and localization requirements.
- Playtest checklist for comprehension and emotional clarity.

## Prototype Validation

The prototype must prove that choices are understandable, consequences are credible, and the UI supports reading flow.

## Asset And UX Needs

- Character identity, emotion state, speaker, choice state, save/load, backlog, and localization layout need readable UI.
- Placeholder portraits are acceptable only if roles and emotion states are clear.

## QA And Playtest Checks

- Can players track speaker, goal, and consequence?
- Are choices meaningful or only cosmetic?
- Does text layout support target languages?

## Explicit Exclusions

- Full script production.
- Final character CG.
- Voice acting.
- Complete route implementation.
