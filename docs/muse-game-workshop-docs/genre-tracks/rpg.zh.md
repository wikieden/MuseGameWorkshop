# RPG / 角色扮演类型分支

状态：Draft  
版本范围：v0.8  
Review Status: Approved

## Player Promise / 玩家承诺

玩家培养角色，做出 build 或队伍决策，并看到成长改变可用选择。

## Core Loop Emphasis / 核心循环重点

```text
接受任务/目标 -> 探索或战斗 -> 获得奖励 -> 提升角色/队伍 -> 解锁新选择 -> 面对更高挑战
```

## Required Deliverables / 必要交付物

- character role matrix / 角色职责矩阵。
- progression map / 成长路径。
- ability unlock table / 技能解锁表。
- quest or objective brief / 任务或目标 brief。
- reward table / 奖励表。
- build choice and party synergy notes / build 选择与队伍协同说明。
- 成长清晰度 playtest checklist。

## Prototype Validation / 原型验证

原型必须证明成长会改变决策，而不只是提高数值。

## Asset And UX Needs / 资产与 UX 需求

- 角色职责、敌人职责、状态效果和成长反馈需要清楚的图标语言。
- UI 可读性属于原型要求，不是后期 polish。

## QA And Playtest Checks / 测试与试玩检查

- 玩家能否识别职责、build 和下一个目标？
- 成长是否带来新选择？
- 奖励是否清楚且有驱动力？

## Explicit Exclusions / 明确不做

- 完整剧情战役。
- 完整经济系统。
- 大型装备库。
- 最终角色美术。
