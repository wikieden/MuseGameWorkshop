# Adventure / AVG Track

Status: Draft  
Version scope: v0.8  
Review Status: Approved

## Player Promise

The player explores scenes, investigates clues, uses items or dialogue, and advances through understandable discoveries.

## Core Loop Emphasis

```text
enter scene -> inspect clue / talk / use item -> update knowledge -> unlock path or dialogue -> advance scene
```

## Required Deliverables

- Scene flow.
- Clue list.
- Interaction table.
- Inventory or item-use rules.
- Dialogue gate notes.
- Failure and hinting plan.
- Playtest checklist for investigation readability.

## Prototype Validation

The prototype must prove that players understand where to look, what changed, and why progression unlocked.

## Asset And UX Needs

- Interactable objects, exits, clue states, inventory state, and dialogue availability must be readable.
- Overly atmospheric visuals cannot hide required information.

## QA And Playtest Checks

- Can players find critical clues without pixel hunting?
- Do item and dialogue gates make sense?
- Does feedback explain state changes?

## Explicit Exclusions

- Full scene list.
- Final background art.
- Full voice or cinematic implementation.
- Large branching narrative.
