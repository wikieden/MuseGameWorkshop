# Visual Novel / 视觉小说类型分支

状态：Draft  
版本范围：v0.8  
Review Status: Approved

## Player Promise / 玩家承诺

玩家跟随角色，做出叙事或关系选择，并看到有意义的剧情后果。

## Core Loop Emphasis / 核心循环重点

```text
阅读场景 -> 理解角色意图 -> 选择回应/路线 -> 看到后果 -> 更新关系/分支 -> 继续
```

## Required Deliverables / 必要交付物

- premise and theme / 前提与主题。
- character brief / 角色 brief。
- route map / 路线图。
- dialogue sample / 对白样例。
- choice consequence table / 选择后果表。
- UI and localization requirements / UI 与本地化需求。
- 理解度和情绪清晰度 playtest checklist。

## Prototype Validation / 原型验证

原型必须证明选择可理解、后果可信，并且 UI 支持阅读流程。

## Asset And UX Needs / 资产与 UX 需求

- 角色身份、情绪状态、说话人、选择状态、存档/读档、backlog 和本地化版式需要可读 UI。
- 占位立绘可以使用，但必须清楚表达角色职责和情绪状态。

## QA And Playtest Checks / 测试与试玩检查

- 玩家能否追踪说话人、目标和后果？
- 选择是否有意义，还是只有装饰作用？
- 文本版式是否支持目标语言？

## Explicit Exclusions / 明确不做

- 完整剧本量产。
- 最终角色 CG。
- 配音。
- 完整路线实现。
