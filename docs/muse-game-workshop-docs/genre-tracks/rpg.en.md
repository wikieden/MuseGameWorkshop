# RPG Track

Status: Draft  
Version scope: v0.8  
Review Status: Approved

## Player Promise

The player grows characters, makes build or party decisions, and sees progression change available choices.

## Core Loop Emphasis

```text
take quest / goal -> explore or fight -> earn reward -> improve character / party -> unlock new options -> face harder challenge
```

## Required Deliverables

- Character role matrix.
- Progression map.
- Ability unlock table.
- Quest or objective brief.
- Reward table.
- Build choice and party synergy notes.
- Playtest checklist for progression clarity.

## Prototype Validation

The prototype must prove that growth changes decision-making, not only numbers.

## Asset And UX Needs

- Character roles, enemy roles, status effects, and progression feedback need clear iconography.
- UI readability is part of the prototype, not a later polish task.

## QA And Playtest Checks

- Can players identify role, build, and next goal?
- Does progression create new choices?
- Are rewards understandable and motivating?

## Explicit Exclusions

- Full story campaign.
- Full economy.
- Large equipment set.
- Final character art.
